# Inference is Metal on macOS, Vulkan elsewhere

This partly supersedes [ADR 0001](0001-whisper-cpp-vulkan.md): whisper.cpp stays the runtime and large-v3 stays the weight, but the GPU backend is now chosen per platform. On macOS whisper.cpp runs on its native Metal backend. On Windows (and any later non-Mac build) it stays on Vulkan. Flash attention is on whenever the GPU is used. If the GPU cannot be set up, that Transcription runs on the CPU, as before.

ADR 0001 took Vulkan everywhere so there would be one GPU path, accepting that Metal would be faster on a Mac. [The benchmark](../whisper-vulkan-vs-metal-bench.md) on an M3 Pro measured that cost. With flash attention on for both, Metal ran inference about 1.6× faster than Vulkan through MoltenVK (30.9 s vs 49.8 s for 213.6 s of audio), its encoder took 619 vs 1150 ms, and it used about 0.5 GB less memory. Both produced the same transcript, and model load time (about 25 s) was the same. MoltenVK exposes no cooperative-matrix extension, so ggml's Vulkan backend only has its generic shaders there; that gap will not close on the Vulkan side. Dropping Vulkan on macOS also removes the Vulkan loader, MoltenVK, shaderc and `VULKAN_SDK` from the Mac build.

The cost is two GPU backends to test: a change to inference has to be checked on a Mac and on Windows. Keeping Vulkan on macOS was rejected because that saving does not pay for a 1.6× slower transcription on the platform most users have. Core ML (the Apple Neural Engine) is still not used; it would be a third backend and needs a separately converted encoder.
