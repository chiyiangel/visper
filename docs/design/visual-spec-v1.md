# Visper 视觉与界面约束 v1

适用范围：Rust + GPUI 实现的 macOS 桌面应用。本文用于开发交付和视觉验收。

设计目标：让导入录音、等待转写、阅读转写稿和回听这些操作清晰、安静、有质感。质感来自稳定的布局、准确的对齐、舒适的文字和细致的状态反馈。

本次设计独立于已有 prototype。功能与术语沿用 `GLOSSARY.md`、产品规格（未随仓库发布）和相关 ADR。本文规定视觉呈现，不改变转写、排队、保存或导出的业务规则。

- **必须**：开发与验收的硬约束。
- **默认值**：除本文明确列出的窗口适配情形外，直接使用此数值，不由各组件单独调整。
- **可调整**：仅用于兼容系统原生控件或字体度量；调整后须保留规定的层级和对齐。

## 2. 整体风格与边界

### 2.1 必须保留的视觉特征

1. **暖白与石墨灰**：浅色模式略带暖感；深色模式采用深灰绿底色，保持文字清晰。
2. **一个主强调色**：低饱和绿用于主要按钮、选中状态、播放定位和进度。警告、失败只在相应状态局部使用语义色。
3. **平整的阅读界面**：以文字、留白和细线划分区域。转写稿是视觉主体。
4. **稳定的桌面布局**：左侧资料库、右侧所选录音详情。选择、转写和播放状态各有独立反馈。
5. **精细而克制的控件**：小圆角、细边框、简洁图标、明确文案；不做厚重立体按钮。

### 2.2 禁止的视觉处理

- 大面积渐变、玻璃效果、背景纹理、噪点、霓虹或发光边缘。
- 装饰插画、3D 图标、无功能用途的波形、仪表盘和统计卡片。
- 超大字号、过重标题、大片品牌色背景、多个高饱和强调色。
- 每一项内容都加卡片、阴影或描边；每个转写分段独立做卡片。
- 页面切换时飞入、弹跳、缩放、闪烁或夸张的过渡。

### 2.3 功能边界

本软件导入用户已有的录音并在本机转写。视觉修改不增加麦克风录制、实时字幕、翻译、摘要、说话人标签、编辑转写稿、搜索、筛选、账号、设置页或主题切换。

语言只有“自动、中文、英文”；导出只有 Markdown；播放只有播放/暂停和点击分段跳转。没有播放速度和独立拖动进度条。转写自动按队列开始，不增加“开始转写”或“暂停转写”按钮。

## 3. 尺寸、间距与窗口适配

### 3.1 单位

本文所有尺寸均为 **逻辑像素 px**，不使用生成图片的物理像素推算布局。高 DPI 屏幕由框架处理缩放。

间距使用 `4、8、12、16、20、24、32、40、48` 这一组值。出现新的间距值时，先检查是否可以用已有值完成布局。

| 项目 | 默认值 / 约束 |
| --- | --- |
| 初始窗口内容区域 | 1120 × 760 px |
| 最小窗口内容区域 | 920 × 620 px |
| 窗口顶部 | 没有通栏标题栏。资料库顶部有一条 52 px 的空白区，交通灯位于其上，位置 (16, 18)；详情头部同为 52 px。两者都是窗口拖动区 |
| 资料库宽度 | 窗口宽度 ≥ 1024 时为 280 px；920–1023 时为 264 px |
| 左右区域分隔线 | 1 px |
| 详情区水平内边距 | 32 px；窄窗口为 24 px |
| 详情头部 | 高 52 px，左内边距同详情区水平内边距，右内边距 16 px，无分隔线 |
| 详情正文顶部内边距 | 4 px |
| 资料库内部水平内边距 | 12 px；标题与页脚文字相对外缘 20 px |
| 区块之间的间距 | 24 px；紧密关联项为 8 或 12 px |
| 同组按钮间距 | 8 px |
| 底部播放区域高度 | 64 px，窄窗口允许增加到 72 px 以容纳换行 |
| 主要分隔线 | 1 px，不额外叠加阴影 |

不提供侧栏拖动调宽、队列拖动重排或窄屏移动端导航。

### 3.2 页面骨架

窗口没有通栏标题栏，而是左右两栏并列，资料库占满窗口高度（与 Claude 桌面版相同）：资料库 | 主栏。窗口保留透明标题栏，交通灯叠在资料库顶部，其余部分不再绘制标题。

资料库从上到下为：52 px 拖动区 → “加入录音”行 → “资料库 / n 份录音”标题行 → 录音列表 → 页脚。

主栏从上到下为：52 px 详情头部 → 可选的模型下载/下载失败提示条 → 可选的通知条 → 详情正文。提示条与通知条只跨主栏，不跨资料库。

详情头部左侧是所选录音的文件名，右侧是该录音的操作；没有选中录音时头部为空，但仍高 52 px、仍可拖动窗口。详情正文从上到下为：路径和状态 → 可选的转写进度或文件提示 → 转写稿 → 底部播放操作。底部播放区域留在详情内，不跨越资料库。

- 资料库顶部区域、“加入录音”、标题和页脚固定，录音列表独立纵向滚动。
- 详情头部和底部播放区域固定，转写稿独立纵向滚动。
- 窗口本身不出现横向滚动条；按钮不能挤出窗口。
- 放大窗口时，优先增加转写稿的可视高度。正文阅读区宽度上限为 880 px，靠左对齐；多余空间留在右侧。
- 下载条出现或消失只改变可用内容高度，不改变左右栏宽度。
- 系统原生窗口边角和外部阴影由系统负责，不额外绘制一层假窗口外框。

### 3.3 长文本与换行

- 资料库文件名使用一行，超长时尾部省略。完整名称可通过提示查看，并在详情显示。
- 详情头部的文件名单行显示，超长时尾部省略，操作按钮始终完整显示且不与文件名重叠；完整文件名由资料库行的提示和路径行呈现。
- 详情中的完整路径使用小字号、次要文字色；在分隔符附近或必要处换行，不只保留无法辨识的路径尾部。
- 正文根据可用宽度自然换行，英文单词优先整体换行，特别长的连续字符串允许断行。
- 路径和错误提示增长时，详情正文头部按内容增高；不得用固定高度裁掉内容。详情头部本身固定 52 px。

### 4.2 使用约束

- 绿色只承担操作、选择、播放定位和完成反馈；普通标题、正文仍使用文字色。
- 等待中、已取消采用中性颜色；失败采用低饱和红；文件缺失采用低饱和琥珀色。
- 状态必须同时有文字；不能只靠颜色或图标表达。
- “文件缺失”是附加标记，不代替录音原来的完成/失败等状态。
- 悬停与选中有明显区别：选中背景持续存在，悬停背景离开后恢复。
- 禁用只影响相关控件，不降低整个详情区或已保存转写稿的透明度。

### 4.3 深色模式

跟随 macOS 系统外观变化，不提供应用内开关。深色模式沿用相同布局、字号、间距和交互，不另做一套页面结构。

深色的主要按钮使用浅绿色底与深色文字；阅读区域使用深灰绿底与暖白文字。不得直接对浅色截图反相，也不得把全部表面改成纯黑。

文件选择、导出目录选择和系统确认框优先使用系统原生控件。系统控件的主题、强调色、交通灯和字体允许遵循系统，不强行重画为应用的绿色。

## 5. 字体与文字层级

英文和数字使用系统无衬线字体，中文使用系统简体中文字体（macOS 下为苹方风格）。实现时确保中英混排有正常回退。时间戳单独使用系统等宽字体。

不要新增字体下载，也不使用衬线字体、手写字体或装饰字体。

| 用途 | 字号 / 行高 | 字重 | 颜色 |
| --- | --- | --- | --- |
| 详情头部文件名 | 14 / 20 px | Semibold 600 | primary |
| 首次使用主标题 | 24 / 32 px | Semibold 600 | primary |
| 区块标题，如转写稿 | 15 / 22 px | Semibold 600 | primary |
| 资料库标题“资料库” | 12 / 18 px | Medium 500 | secondary |
| 资料库录音计数“n 份录音” | 12 / 18 px | Regular 400 | tertiary |
| 加入录音 | 13 / 20 px | Medium 500 | primary |
| 资料库分组标题 | 11 / 16 px | Medium 500 | tertiary |
| 资料库文件名 | 13 / 20 px | Medium 500；选中为 600 | primary |
| 按钮与语言选项 | 13 / 20 px | Medium 500 | 按组件状态 |
| 转写稿正文 | 15 / 24 px | Regular 400 | primary |
| 转写分段时间戳 | 12 / 24 px | Regular，等宽 | secondary |
| 路径、行内状态、辅助说明 | 12 / 18 px | Regular 400 | secondary |
| 格式说明、计数 | 11 / 16 px | Regular 400 | tertiary |

- 中文、英文正文的字号与行高一致，不因语言切换而改变样式。
- 正文不加粗整段；播放定位使用背景反馈，不改变字重。
- 详情头部的文件名是工作区主标题，不额外再加一个大号页面标题。
- 使用简体中文界面文案；术语固定为“录音、转写、转写稿、分段、资料库”。
- 时间戳固定 `HH:MM:SS`，包括不足一小时的录音；例如 `00:01:16`。
- 转写进度与播放时长可采用 `MM:SS`，超过一小时切换为 `HH:MM:SS`；同一组已处理/总时长使用相同格式。

## 6. 圆角、边框、图标与阴影

| 元素 | 规范 |
| --- | --- |
| 普通按钮、语言控制整体 | 8 px 圆角 |
| 资料库选中行、播放分段背景 | 8 px 圆角 |
| 提示条、进度区块 | 8 px 圆角，最多一层细边框 |
| 应用自绘弹层 | 10 px 圆角 |
| 播放主控 | 36 × 36 px 圆形；图标 16 px |
| 进度条 | 4 px 高，端头半圆 |
| 普通图标 | 16 px；录音文件图标可为 20 px |
| 空状态标记 | 首次使用宽 132 px，未选中录音宽 72 px；比例 910 : 520 |
| 自绘线性图标描边 | 1.5 px，统一端点风格 |

标记（Mark）由 V 形和右侧两条“文字线”组成，视口 `180 400 910 520`。V 形描边 140、两条线描边 70，端点与拐角均为圆形。两部分各自是独立的 svg（`mark-vee.svg`、`mark-lines.svg`），因为 GPUI 只能把一个 svg 染成一种颜色；绘制时叠放，线在下、V 形在上。标记只用于首次使用、未选中录音和转写中的提示，不当作 logo 贴在界面各处。

同一套图标统一使用线性风格。不要混用彩色表情、不同描边粗细和 3D 图标。录音使用音频文件图标，不用麦克风图标暗示现场录音。

普通列表行、正文、按钮不使用投影。仅自绘弹层可使用低强度阴影：偏移 `0, 8`、模糊 `24`、黑色不透明度浅色 12%、深色 24%。系统弹层使用系统阴影，不再叠加。

参考图深色转写稿中的外框和逐行细线不作为必须还原的元素；统一实施为平整阅读区域，通过留白分隔分段。

## 7. 通用组件约束

### 7.1 按钮

默认高度 32 px，圆角 8 px，水平内边距 12 px；带图标时左内边距 10 px，图标与文字间距 6 px；主要按钮右内边距 14 px。纯图标按钮固定 32 × 32 px，只放 16 px 图标并几何居中，悬停 500 ms 后显示文字提示（墨色底、12 px 文字、6 px 圆角）。播放按钮为 36 px 圆形，同样只放图标。首次使用页中心“选择录音”高度 40 px、水平内边距 20 px。

| 类型 | 默认 | 悬停 / 按下 | 使用位置 |
| --- | --- | --- | --- |
| 主要按钮 | accent 底色、onAccent 文字，1 px 下投影（10%） | 渐变到 accent.hover；按下即时 pressed | 空状态选择录音、播放 |
| 次要按钮 | raised 底、1 px border、primary 文字，1 px 下投影（5%） | 底色与边框各叠加 4% / 6% 墨色；按下 8% | 导出 Markdown、重新转写、取消转写、重试 |
| 文字按钮 / 图标按钮 | 无底、无框；图标为 secondary | 叠加 6% 墨色，图标渐变到 primary；按下 11% | 关闭、更多操作 |
| 破坏性按钮 | danger 文字；确认框最终操作可用 danger 底 | 同色系加深；文案清晰 | 从资料库移除 |
| 禁用按钮 | border 与中性表面，disabled 文字 | 无悬停、无按下反馈、无操作 | 当前不可用的导出、回听、重新转写 |

同一个局部操作区只突出一个主要动作。资料库里的“加入录音”是全局动作，做成资料库的一行而不是按钮（见 8.1）；详情区的导出、重新转写都用次要按钮，不再与它争夺注意力。

禁用控件必须由行为层阻止操作，不能只修改颜色。当前转写中的语言选项保留选中值，但不能切换。

### 7.2 焦点与反馈

- 焦点环只在用 Tab 键移动焦点时显示，鼠标点击不显示；之后任何一次鼠标按下都会收起焦点环。
- 独立控件的焦点环为 2 px accent 外框，与控件间隔 2 px，圆角 = 控件圆角 + 4 px，四边与四角粗细一致；资料库行、语言选项这类紧挨着的控件把 2 px 外框画在内侧。不改变控件尺寸。不要用阴影外扩来画焦点环：GPUI 的阴影外扩时圆角不随之放大，四角会比四边粗。
- 保留原生控件的基本键盘操作和可访问名称，不新增自定义快捷键。
- 状态、分组标题、路径和装饰图标不显示按钮悬停反馈。
- 悬停进入和离开都用 120 ms ease-out 渐变，变化仅限颜色和背景；按下即时生效、不带过渡。不缩放或移动控件。
- 进度条更新可用最长 160 ms 的平滑变化，数值必须对应实际进度，不凭动画推算。
- 遵循系统减少动态效果偏好；开启时移除自绘过渡。
- 操作反馈就近显示；导出成功可在详情操作附近显示“已导出”，约 3 秒后消失，不新增系统通知。

### 7.3 语言分段控制

顺序固定为“自动｜中文｜英文”，整体高度 32 px、默认宽 216 px，每项等宽。整体为 surface.track 底槽、8 px 圆角、无外框，内边距 2 px。选中项由一块 raised 滑块（6 px 圆角、轻投影代替描边）承托，切换时滑块用 180 ms 滑到新选项；选中文字为 primary，其余为 secondary，悬停时渐变为 primary。

只在等待中显示这个控件并允许设置。转写开始后不再显示一个灰掉、点不动的控件，而是和完成后一样写一行文字（“自动识别语言”“中文”或“英文”）；用户需要更换语言时，按既有取消/重新排队规则处理，不绕过业务锁定。

### 7.4 进度条与状态

进度填充使用 accent；轨道使用 border。显示已处理时长/录音时长和实际百分比。

剩余时间只能从实测的速度推算，不能凭进度条动画猜：速度 = 已处理音频时长 ÷ 已用时，剩余 = 未处理音频时长 ÷ 速度。规则：

- 已用时从录音变为转写中那一刻开始计，每秒刷新。退出后再启动重新排到的转写从启动时重新计。
- 前 30 秒或进度不到 3% 时速度还不稳定，标题写“正在估算剩余时间…”（secondary、Medium），不给数字，也不显示速度。尚无进度（正在准备录音）时标题写“正在准备录音…”。
- 之后标题写“还需约 N 分钟”（按分钟向上取整，Semibold、primary），一小时以上写“还需约 1 小时 10 分钟”，不到一分钟写“还需不到 1 分钟”。剩余一分钟以上时，旁边小字写“预计 HH:MM 完成”（本地时间）。
- 估算每 5 秒重算一次，两次之间只按流逝的时间往下减，避免数字来回跳。
- 进度区为 raised 底、1 px border、10 px 圆角，内边距上 14 / 左右 16 / 下 12 px，三行间距 10 px：标题与“取消转写”；进度条与百分比；“已用时 / 已处理 / 速度”，数值用等宽字体、primary 颜色。
- 完成后进度区消失，“转写用时 MM:SS”保存在资料库里，显示在详情的录音信息行和资料库行（“· 42:18 · 用时 09:37”）。只在完成状态显示；没有这项记录的旧资料库不显示。

等待中用中性圆点，转写中用绿色圆点及文字，完成用小对勾及文字，失败用错误标记及文字，已取消用中性标记及文字。状态图标尺寸 12–14 px，避免大徽章。

## 8. 资料库

### 8.1 固定结构

自上而下：

1. 52 px 空白拖动区，交通灯在其上。
2. “加入录音”行，左右内边距 12 px、下 8 px：整行高 36 px，水平内边距 10 px，圆角 8 px，图标与文字间距 10 px；左侧是 22 px 的 accent 圆，内含 12 px 加号（比普通加号更粗，描边 2.5，颜色 onAccent），右侧文字 13 / 20 Medium primary。悬停时圆渐变到 accent.hover，行底叠加 5% 墨色，按下 9%；与资料库行一样用内侧焦点环。点击打开选择文件。
3. 标题行，内边距 8 / 20 / 0：左“资料库”，右“n 份录音”，同一基线。
4. 录音列表与页脚。

录音按“转写中 → 等待中 → 已结束”顺序分组，分组标题不接受点击，不承担筛选功能。分组标题上方 10 px、下方 4 px。

参考图中的“已完成”在实施时统一为 **“已结束”**，因为该组同时容纳完成、失败、已取消；具体状态仍显示在录音行内。这只是分组标题的文字统一，不改变状态定义。

- 转写中最多一条，固定在最前。
- 等待中按加入顺序排列。
- 已结束按结束时间倒序排列。
- 空组隐藏；没有录音时不显示三个“0 条”分组。
- 资料库底部使用小锁图标和“本机转写”，不显示模型后端、线程数等实现细节。

### 8.2 录音行

普通录音行默认高 60 px；包含转写进度时为 76 px。内部水平内边距 12 px、垂直 10 px；文件图标与文字间距 10 px。

第一行是文件名，第二行是状态或时长/语言；实际数据不存在时不显示占位猜测值。转写中第二行写剩余时间（“· 还需约 11 分钟”或“· 正在估算…”），并额外显示 4 px 进度条；完成后写时长与转写用时。第二行过长时以省略号截断。

选中整行使用 selection 背景和 8 px 圆角；同一时刻只能有一条选中。选中属于浏览位置，转写中属于运行状态，播放属于回听状态，三者不得混为一个标记。

正在转写的录音未被选中时，仍显示其转写状态与进度；用户阅读另一份转写稿不会使其消失。

## 9. 详情与转写稿

### 9.1 详情头部

文件名与常用操作在 52 px 的详情头部（见 3.2）；其下的正文头部依次呈现完整路径、状态/时长/语言。

- 有已保存分段时，突出“导出 Markdown”。
- 重新转写是次要操作，按业务状态启用。
- “从资料库移除”放在更多操作中，避免与日常操作并列突出。
- 正在转写时显示语言锁定值和转写进度。
- 正文头部与转写稿之间用一条细线分隔，不叠加投影；详情头部与正文之间不画线。

### 9.2 转写稿正文

区块标题为“转写稿”。完成时可显示“点击分段，从此处回听”；转写中显示“分段实时显示”。

每个分段为时间戳与正文两列：时间戳列宽 64 px，列间距 8 px，正文使用剩余宽度。分段之间不留额外间距，每段上下内边距 3 px、左右 10 px；正文 15 / 24 px，时间戳 12 / 24 px 等宽。所有分段共享同一对齐线，读起来像连续的文章。

- 时间戳显示分段开始时间，不显示说话人名称或结束时间。
- 允许选择、复制正文；不显示编辑工具栏、输入光标或可编辑文本框样式。
- 整段可响应回听定位，文字选择操作须正常工作，不能把拖动选择误判为点击播放。
- 当前播放分段使用 playback 背景和 8 px 圆角，时间戳变为 accent 并加粗；不加左侧竖线。所有分段内边距相同，切换高亮时文字不移动。
- 鼠标悬停叠加 4% 墨色、时间戳渐变为 accent，比播放高亮弱，不能让多个分段同时看起来正在播放。
- 新分段追加不能抢走焦点或把用户正在阅读的位置跳回顶部。仅当用户已停在末尾时，允许随内容跟随到底部。
- 长转写稿正常滚动，不因为段数多缩小正文或减少行高。

### 9.3 底部播放区域

顶部仅一条细分隔线。左侧为 36 px 播放/暂停按钮、状态文字和当前/总时长；右侧为小字号“点击分段跳转”。

播放控件不出现独立拖动条、可编辑时间、速度和音量控制。没有可播放条件时显示禁用状态；文件缺失时就近说明“原录音文件缺失，无法播放”。

完成但转写稿为空时，只要原录音存在，播放仍可用，导出不可用。

## 10. 五个主要场景的呈现约束

### 10.1 首次使用与模型下载

下载条在主栏顶部的详情头部之下，只跨主栏，默认高 64 px；左侧下载图标、标题与说明，中间或下方细进度条，右侧已下载/总量。窄窗口允许高度增至 80 px。

推荐文案：

- 主标题：“正在准备转写模型”。
- 说明：“首次使用需下载一次，之后可离线转写”。
- 数值示例：“1.8 / 3.1 GB”；显示实际数据。

首次下载自动开始，没有取消按钮。失败时在同一区域显示错误与“重试”，不另起一个页面。下载完成后收起该条，减少长期占用。

空资料库左侧只有“资料库、0 份录音、还没有录音”。右侧内容组水平居中，位于内容区高度约 45% 处；组宽不超过 440 px：标记（132 px 宽）→ 主标题 → 说明 → 选择录音按钮 → 支持格式 → 本机保留说明。

主标题“把录音变成文字”；说明“拖入录音，或选择本机文件”；支持格式“M4A · MP3 · WAV · FLAC · AAC”；隐私说明“录音与转写稿保留在本机”。

标记只在首次出现时播放一次动画：V 形用 360 ms 淡入；两条线在 280 ms 后用 520 ms（ease-out）自左向右写出。之后静止，不循环。

空态可使用一层极淡的虚线投放边界，内边距 32 px。实际拖入合法文件时，边界变为 accent 并显示清晰的落点反馈。下载未完成也可加入录音。

### 10.2 等待与转写中

等待中显示“等待中”和可设置的语言。若模型尚未就绪，详情说明“模型准备完成后自动开始”。

转写中显示：剩余时间、已用时、实际进度、已处理/总时长、速度、语言文字、“取消转写”、实时分段（见 7.4）。进度区域内边距 16 px；不添加装饰波形。尚无分段时显示“正在转写，分段将在这里显示”。

有分段时，转写稿末尾写“正在转写后续内容…”，前面是一个 14 px 宽的“书写”图标：两条 3 px 高的圆角线，上下间距 3 px；上线 14 px 宽、accent 色，下线 11 px 宽、`mark.lines` 色，向右缩进 3 px。两条线依次从零宽写到满宽，停留片刻后淡出，每 1.4 s 循环一次，下线比上线晚 0.18 s。这是唯一的循环动画，不用于其他地方。

没有选中录音但资料库里有录音时，右侧居中显示 72 px 宽的淡色标记（`mark.vee.faint`、`mark.lines.faint`，不做动画）和“选择左边的一条录音”。

有分段后可按业务条件回听。首次转写没有已保存转写稿时，导出禁用。重新转写时显示新分段，并在导出附近提示“导出使用上次已保存的转写稿”。

### 10.3 完成与分段回听

完成状态用小对勾和“完成”。隐藏转写进度区、取消操作、后续内容活动提示；保留时长和实际语言。主要操作为导出，次要操作为重新转写。

播放时高亮当前分段，按钮显示暂停图标，显示“正在播放”。暂停后保留播放位置，状态改为“已暂停”。

无可识别文字但转写成功时，仍显示“完成”，正文区显示“录音中未得到可转写的文字”；这不是失败状态。

### 10.4 导出 Markdown

点击导出进入系统原生目录选择流程，文件名按录音名称生成 `.md`。参考图表达保存意图，不要求照图自绘文件浏览器。

优先保留原生目录浏览、取消、确认的交互。若能够设置确认按钮标题，使用“导出”。不要增加格式列表、内容预览编辑器或额外导出选项。

只导出已保存分段，重转写过程中的实时分段不混入导出。已有同名文件按既有产品规则覆盖，不额外改变流程。导出后不自动打开文件或 Finder。

应用内的说明和结果反馈沿用字体、间距和语义色；原生系统弹窗采用系统样式。

### 10.5 文件缺失与失败

文件缺失时保留原状态，并显示额外标记。详情提示采用 warning 背景、小警告图标、标题和说明，内边距 16 px。

文案为“找不到原录音文件”“转写稿已保留，可继续阅读和导出。”。只有存在已保存分段时才使用后一条说明；保存的是空转写稿时改为“空转写稿已保留，原录音文件缺失，无法播放或重新转写。”；没有已保存转写稿时改为“无法读取原录音文件，转写和播放不可用。”。

已有转写稿正常高对比度显示；播放和重新转写禁用；有已保存分段时导出仍可用。不要把全屏涂成警告色，不增加“重新关联文件”等未定义的功能。

转写失败使用 danger 提示，显示实际错误原因。存在上次转写稿时恢复其显示并说明“上次转写稿已保留”；不存在时不留下半成品文字。有原录音时提供“重新转写”次要操作，不自动重试。

## 11. 操作可用状态表

此表用于检查视觉禁用状态是否与产品行为一致。录音均假设原文件可读；文件缺失是另加的限制。

| 情形 | 修改语言 | 播放 | 导出 Markdown | 重新转写 | 取消转写 |
| --- | --- | --- | --- | --- | --- |
| 等待中，首次转写 | 可 | 不可 | 不可 | 不可 | 不可 |
| 等待中，已有上次转写稿 | 可 | 可 | 已保存分段非空时可 | 不可 | 不可 |
| 转写中，首次转写 | 不可 | 已显示分段时可 | 不可 | 不可 | 可 |
| 转写中，重新转写 | 不可 | 可，已有上次转写稿 | 已保存分段非空时可，使用上次结果 | 不可 | 可 |
| 完成，分段非空 | 不可，显示实际语言 | 可 | 可 | 可 | 不可 |
| 完成，分段为空 | 不可，显示实际语言 | 可 | 不可 | 可 | 不可 |
| 失败/已取消，已有上次转写稿 | 不可，显示实际语言 | 可 | 已保存分段非空时可 | 可 | 不可 |
| 失败/已取消，无已保存转写稿 | 不可，显示实际语言 | 不可 | 不可 | 可 | 不可 |

文件缺失时：播放与重新转写不可用，导出仍按已保存分段是否非空决定。等待中的取消需求通过“从资料库移除”按既有规则处理，不增加“取消等待”操作。

已保存转写稿存在（包括完成但为空）时，移除需要确认；没有已保存转写稿时按产品规则直接移除。确认文案明确“已保存的转写稿将被移除，原录音文件会保留。”。有上次转写稿的正在转写项，确认前不提前取消其运行。

## 12. GPUI 实现交付要求

1. 将颜色、字体尺寸、间距、圆角归入统一 token 定义。现有 `src/ui.rs` 中的 `Palette` 可扩展为语义主题，但控件不应自行写独立颜色值。
2. 浅色和深色由窗口外观统一决定，变化后整窗更新；不靠组件分别猜测主题。
3. 共享按钮、资料库行、状态标记、语言控制、分段行和提示条的绘制规则，避免每个页面各自实现一套。
4. 以状态数据决定显示与启用条件。图片中的百分比、时长、路径、录音数是示例，不写死进产品。
5. 保留透明标题栏与文件对话框能力；交通灯、窗口拖动（资料库顶部和详情头部的 52 px 区域）、缩放、系统滚动应正常工作。
6. 视觉改造与功能开发分开验收。尚未实现的状态可用开发用例或预览数据检查，但不能在生产界面伪造进度、结果或可用操作。

## 13. 验收清单

### 13.1 视觉

- [ ] 所有颜色来自本文主题 token；绿色使用范围克制。
- [ ] 浅色为暖白，深色为深灰绿；系统切换外观后无残留浅色块或错误文字色。
- [ ] 字号、字重、行高符合表格；中英混排和时间戳没有跳动。
- [ ] 标题、正文、状态、按钮形成清楚的层级，正文阅读最舒适。
- [ ] 侧栏、头部、正文和播放区域对齐；同类控件尺寸统一。
- [ ] 没有逐段卡片、额外阴影、装饰波形、渐变和大面积警告色。
- [ ] 点击、悬停、焦点、选中、播放定位、禁用分别有明确且一致的反馈。

### 13.2 布局与内容

- [ ] 在 920 × 620、1120 × 760、1440 × 900 三种逻辑尺寸下均可正常使用。
- [ ] 录音文件名很长、路径很长、英文长句、中文多行时没有重叠或横向滚动。
- [ ] 100 条录音和 1000 个分段仍保持正常滚动与阅读尺寸；数字是验收样例，不是产品限制。
- [ ] 两个滚动区域相互独立，头部操作和底部播放区域稳定。
- [ ] 用户在中间阅读时，新分段不会强制滚动或抢焦点。
- [ ] 图片中的装饰、窗口外部背景和数据未被误当成产品内容。

### 13.3 状态与行为

- [ ] 五个参考场景均可在真实或开发预览数据下检查，并覆盖浅/深色。
- [ ] 下载中可加入录音；下载失败的重试位置与原进度位置一致。
- [ ] 转写中的语言不可切换，导出与播放的可用性符合状态表。
- [ ] 阅读另一份转写稿时，正在转写的录音仍在资料库最前显示状态。
- [ ] 点击分段跳转和正文拖动选择互不冲突；没有独立播放拖动条。
- [ ] 文件缺失不抹掉原状态或已保存转写稿；可导出与不可播放有清楚表达。
- [ ] 完成但空转写稿、首次失败、重新转写失败、取消、缺失无转写稿均有恰当呈现。
- [ ] 移除确认与导出遵循现有业务规则，原生对话框正常工作。

建议开发人员交付五个主要场景的截图，并提供至少一组最小窗口、深色模式和长内容截图；对照本清单逐项验收。
